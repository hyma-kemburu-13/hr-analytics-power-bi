HR Analytics Dashboard — Power BI

Project Overview

This project explores employee data using Microsoft Power BI to understand workforce characteristics and employee attrition.

Tools Used

- Microsoft Power BI
- Power Query for data cleaning
- DAX for calculations

Work Completed

- Imported an Excel practice dataset into Power BI.
- Cleaned the data using Power Query.
- Created KPI cards and charts to summarize employee information.
- Created an Attrition Count calculated column.
- Calculated the attrition rate using DAX.

Key Metrics

- Total Employees: 1,416
- Total Attrition: 229
- Attrition Rate: 16.2%
- Average Age: 36.92
- Average Years at Company: 7.04
